# Selección de testimonios — 21 septiembre 2026

Revisados mediante computer use en Safari, en la sesión de X del usuario. Búsqueda `hackspain`, pestañas Latest y Top. Selección inicial, no inventario exhaustivo. Se mostró el original de las publicaciones traducidas automáticamente por X. No se cambiaron likes, reposts ni bookmarks.

Los ocho seleccionados están en `src/data/recap.ts`, con texto original, nombre, handle y permalink. La landing utiliza embeds oficiales de X a partir de esos enlaces. X carga los avatares y medios; no se descargan ni se recrean en tarjetas propias. Si el widget no carga, se conserva un enlace a la publicación original.
